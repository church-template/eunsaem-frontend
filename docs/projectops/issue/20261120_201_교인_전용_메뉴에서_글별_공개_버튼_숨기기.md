📝 현재 문제점
---

- 설교나 갤러리 메뉴 전체가 교인 전용인데도, 관리자에게는 글마다 "누구나 공개" 버튼이 보인다. 지금 밖에 공개된 것처럼 읽혀서 오해가 생긴다.
- 실제로 은샘 관리자가 설교 11편의 버튼을 하나씩 눌러 교인만으로 바꿨다. 메뉴 전체가 교인 전용인 동안에는 이 버튼이 아무 효과가 없다.
- 교인에게도 글마다 "교인만" 배지가 붙어, 전부 교인 전용인 목록에서 일부만 다르게 보인다.

🛠️ 해결 방안 / 제안 기능
---

- 메뉴 전체가 교인 전용이면 목록과 상세의 글별 버튼과 "교인만" 배지를 숨긴다.
- 목록 위 안내문 옆에 "열기 전에 교인 전용 글 고르기" 링크를 둔다. 누르면 버튼이 나타나고, 글자는 "열면 공개" / "열어도 교인만"으로 보인다. "고르기 끝내기"로 다시 숨긴다.
- 공개 범위 설정 화면의 설교·갤러리 줄에도 같은 링크를 둔다.
- 등록·수정 화면의 교인만 보기 체크박스 아래에, 메뉴가 교인 전용일 때는 누구나로 열었을 때만 적용된다는 안내를 붙인다.
- 메뉴가 누구나일 때의 화면은 바꾸지 않는다.
