📝 현재 문제점
---

- 홈 화면에서 히어로(십자가 → 영상) 아래 구간이 밋밋하다. 카드와 글만 나열돼 있고 눌러 볼 것이 없다.
- 히어로 끝의 사진 콜라주는 설명 없는 사진 4장이 크기도 제각각이라 무슨 장면인지 알 수 없고 어색하다.
- 연혁은 색 카드 7장에 글만 있고, 각 연도의 실제 사진(`public/history/*`)을 쓰지 않는다.
- 최신 설교는 같은 크기의 카드 3장이라 "이번 주 말씀"이 눈에 띄지 않는다.
- 우리의 사역, 예배 시간, 공지, 일정도 정적인 카드 나열이다.

🛠️ 해결 방안 / 제안 기능
---

히어로의 십자가 → 영상 연출은 그대로 두고, 그 아래 섹션을 인터랙티브하게 바꾼다. 확정 시안은 `docs/projectops/ui-design/20261111_001_메인_인터랙티브_개선/screens/home-v5.html`(전부 A안).

- **콜라주 → "이렇게 모이고, 나눕니다"**: 왼쪽 큰 사진 + 오른쪽 4줄 목록. 줄을 누르면(PC는 올려도) 사진이 바뀌고 설명이 펼쳐진다. 6초마다 자동으로 넘어간다. 히어로 끝에서 영상이 사진 4장으로 흩어지는 장면은 제거한다.
- **연혁 → 그려지는 타임라인**: 가운데 세로선이 스크롤만큼 채워지고, 선이 닿은 연도의 사진과 글이 좌우 번갈아 나타난다.
- **최신 설교 → 말씀 띠 + 지난 말씀**: 가장 최근 설교를 다크 띠로 크게 세우고, 지난 설교는 날짜 줄 목록으로 둔다(설교 목록 페이지와 같은 모양).
- **우리의 사역 → 사진 패널**: 패널 3장이 누르면(PC는 올려도) 펼쳐지며 설명과 링크가 나온다.
- **예배 시간 → 다음 예배 띠 + 요일 선택**: "다음 예배까지 남은 시간"을 한국 시간 기준으로 보여 주고, 요일을 누르면 그날 예배만 강조한다.
- **공지, 일정 → "교회 소식" 탭**: 두 섹션을 탭 하나로 묶는다.
- **서브타이틀**: 섹션 제목 위 작은 글씨(은샘교회의 한 주, 연혁)를 22px로 키운다.
- **모바일**: 폰에는 호버가 없으므로 호버로만 볼 수 있는 정보를 두지 않는다. 탭으로 동작하거나 처음부터 보이게 한다.
