📝 현재 문제점
---

- 새누리는 부서를 "미션팀"으로, 은샘은 "사역"으로 부른다. 은샘도 "부서"로 부르기로 했다.
- #181에서 부서 사진·소개를 관리 화면에서 바꾸는 구조를 넣었지만, 운영 서버에 부서가 없어 상수의 백엔드 id(`backendId`)를 비워 두었다. 그래서 관리 화면에서 고쳐도 공개 페이지에 반영되지 않는다.
- 운영 서버에 부서 5개를 넣었다(2026-11-16). id는 학생부 7, 청년부 8, 예배부 9, 남선교회 10, 여선교회 11이다. 소개 글은 지금 상세 페이지에 보이는 문구를 그대로 넣었다.

🛠️ 해결 방안 / 제안 기능
---

- 부서를 가리키는 "사역" 표기를 "부서"로 바꾼다.
- 상수의 부서 5개에 백엔드 id를 연결해 새누리와 같이 API로 사진·소개를 읽게 한다.
