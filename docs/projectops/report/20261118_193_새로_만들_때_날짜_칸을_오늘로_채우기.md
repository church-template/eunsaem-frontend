# 🚀[기능개선][관리] 새로 만들 때 날짜 칸을 오늘로 채우기

## 개요

새로 만드는 화면의 날짜 칸이 설교 등록만 오늘로 채워지고 나머지는 비어 있었습니다. 주보 · 일정 · 성경통독 챌린지 · 차량 운행일도 한국 시간(KST) 기준 오늘(시각 칸은 지금)로 채워서 열리게 했습니다. 수정 화면은 저장된 값을 그대로 보입니다. (PR #194)

## 주요 구현 내용

- **시각은 `formatToParts` + `hourCycle: "h23"`로 조립합니다.** 로케일에 따라 자정이 `24`시로 나올 수 있어, 날짜가 넘어간 직후에도 `00`시가 되도록 고정했습니다. 시간대는 `Asia/Seoul` 고정이라 서버나 테스트 러너의 시간대와 무관합니다.
- **챌린지·운행일은 창을 열 때 계산합니다.** 기본값을 모듈 상수에 넣으면 창을 열어 둔 채 자정을 넘길 때 어제 날짜가 남습니다. 창이 열릴 때의 `reset`에서 계산합니다.
- **수정은 저장값을 그대로**: 주보·일정은 `initial`이 있으면 저장값, 챌린지·운행일은 수정 대상이 있으면 저장값으로 채웁니다.

## 검증

- 새 테스트: 일반 시각과 자정 직후(`00:05`), 네 폼의 새로 만들기 기본값, 주보·일정·운행일의 수정 시 저장값 유지
- 기존 테스트 1건 수정: 차량 폼의 "출발 시각 미선택 제출" 테스트는 기본값이 생기면 전제가 바뀌어, 칸을 비운 뒤 제출하도록 고쳤습니다
- 관련 테스트 통과, `pnpm lint` 오류 0, 소스 타입 오류 0. 전체 테스트의 기존 실패(`main`과 같은 16개 파일)는 그대로입니다
- 실제 화면: 수정 전(`7e9c9ee`)과 수정 후(`main`)를 각각 띄워 네 폼의 칸 값을 읽어 비교했습니다(위 표)

## 주의사항

- 일정 시작은 "오늘 날짜 + 지금 시각"입니다. 정시나 고정 시각(예: 오전 11시)이 낫다면 바꿀 수 있습니다.
- 주보 예배일은 오늘입니다. "다가오는 일요일"로 맞추는 것은 범위 밖으로 남겼습니다.
