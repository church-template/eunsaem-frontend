# 활동 사진 서버로 옮기고 더보기 추가

## 개요

활동 사진은 계속 늘어나는데, 코드에 정적 파일로 들어 있으면 추가할 때마다 개발 요청이 필요하다. 부서 활동 사진 20장과 상수의 사진 목록을 코드에서 빼고, 관리 화면에서 부서에 연결한 앨범으로만 받게 했다. 사진이 많아질 것에 대비해 새누리처럼 8장씩 보여 주고 "사진 더 보기"로 이어서 연다. [PR #187](https://github.com/church-template/eunsaem-frontend/pull/187)로 `main`에 병합했고 아직 배포하지 않았다.

## 변경 사항

### 활동 사진을 서버로
- `public/dept/{student,youth,praise,men,women}/1~4.webp` 20장과 `src/constants/departments.ts`의 활동 사진 목록을 삭제했다. 원본은 담당자에게 부서별 폴더로 전달했고, 코드에 있던 파일과 바이트까지 같은 것을 확인했다(서버 업로드용).
- 예배 안내 대표 사진으로 쓰던 예배부 1번 사진은 `public/worship-hero.webp`로 옮겨 그대로 쓴다. `src/constants/content.ts` 경로 수정.
- 부서 대표 사진(`public/dept/{부서}.webp`)은 남겼다. 관리 화면 대표 사진이 비었을 때의 대체 화면이다.

### 사진 더 보기
- `src/components/departments/DeptGallery.tsx`: 8장씩 보여 주고 "사진 더 보기" 버튼으로 8장씩 더 연다(새누리와 같은 규칙). 처음 8장은 기존 큰 사진 배치(bento)를 유지한다. 크게 보기는 펼치지 않은 사진까지 전체를 넘긴다. 썸네일은 지연 로딩한다.
- `src/constants/departments.ts`: "사진 더 보기" 문구 상수 `galleryMore`, `src/app/departments/[slug]/page.tsx`에서 연결
- `.claude/rules/DESIGN.md`: `dept-gallery` 항목 갱신

## 주요 구현 내용

- **활동 사진이 없으면 구간째 숨는다.** 상수에 사진이 없으므로, 앨범을 연결하기 전에는 활동 사진 구간이 나오지 않는다.
- 테스트를 먼저 썼다(8장 초과면 8장만 보이고 더 보기로 나머지 열기, 8장 이하면 버튼 없음, 라이트박스가 펼치지 않은 사진까지 넘김, 상수에 정적 활동 사진이 없음). 테스트 1177개, 타입 검사, 린트(오류 0) 통과.
- 실제 은샘 서버 주소로 빌드해 예배 안내 페이지가 옮긴 사진(`worship-hero.webp`)을 가리키고, 지운 사진 경로를 가리키는 곳이 없는 것을 확인했다.

## 주의사항

- **배포 전에 서버에 사진을 올리고 앨범을 연결한다.** 연결 전에 배포하면 부서 페이지에서 활동 사진 구간이 사라진다.
- 앨범을 부서에 연결하면 그 앨범의 사진 전체(연결 뒤 추가한 사진 포함)가 누구에게나 공개된다. 관리 화면의 앨범 선택 창에 안내 문구가 있다.
- 사진을 올릴 때는 #188(업로드 전 WebP 변환)이 배포된 뒤에 올린다. 전달한 20장은 이미 WebP로 줄인 파일이라 변환 여부와 상관없지만, 새로 찍은 사진은 원본 위치정보가 남을 수 있다.
