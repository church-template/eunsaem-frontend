# 사역을 부서로 바꾸고 API 연결

## 개요

새누리는 "미션팀", 은샘은 "사역"이라 부르던 것을 은샘도 "부서"로 바꾸고, #181에서 만든 부서 사진·소개 API 연결을 은샘 부서 5개에 적용했다. 운영 서버에 부서 5개를 넣었고(학생부 7, 청년부 8, 예배부 9, 남선교회 10, 여선교회 11), 상수에 그 id를 연결했다. 이제 관리 화면에서 고친 대표 사진·활동 사진·소개 글이 공개 부서 페이지에 반영된다. [PR #185](https://github.com/church-template/eunsaem-frontend/pull/185)로 `main`에 병합했고 아직 배포하지 않았다.

## 변경 사항

### "사역" → "부서"
- `src/constants/navigation.ts`: 헤더 메뉴, 푸터 열 제목
- `src/constants/departments.ts`: `/departments`의 작은 제목 "부서", 큰 제목 "부서 안내", 빈 목록 안내 "등록된 부서가 없습니다", 큰 문구 "함께 섬기는 부서"
- `src/app/departments/page.tsx`: 검색용 설명 "은샘교회의 부서를 소개합니다"
- `src/constants/content.ts`: 홈 카드 버튼 "부서 보기"
- 그대로 둔 것: 홈 "우리의 사역" 섹션(교회가 하는 일 소개), 부서 소개 문장 속 "~사역입니다", 연혁 문구

### 부서 API 연결
- `src/constants/departments.ts`: 부서 5개에 `backendId` 7~11 연결(slug 기준 student, youth, praise, men, women)
- 테스트: "은샘 부서에는 아직 id가 없다"는 전제의 테스트 3개를 id 연결 상태에 맞게 수정. id가 없으면 서버를 부르지 않는 동작은 단위 테스트에서 계속 확인한다.

## 주요 구현 내용

- **병합 직후 화면은 이전과 같다.** 서버 소개 글에 지금 상세 페이지의 문구를 그대로 넣었고, API 글이 그려지는 `prose-church`와 기존 소개 글이 같은 글자 크기(`body-lg`)·색(`body`)을 쓴다. 대표 사진·활동 사진은 관리 화면에서 연결하기 전까지 지금 사진이 나온다.
- **서버 조회가 실패해도 화면은 상수로 그대로 나온다.** 칸마다 따로 대체한다.
- 확인: 실제 은샘 서버 주소로 빌드했을 때 부서 목록·상세가 60초 갱신(ISR)으로 생성되고, 학생부 상세 HTML에 서버 소개 글과 "부서" 메뉴가 들어가는 것을 확인했다. 테스트 1173개, 타입 검사, 린트(오류 0) 통과.

## 주의사항

- **배포는 `main → deploy` 릴리스 PR로 한다.** 아직 나가지 않았다.
- **배포 후 확인:** 관리 화면에서 부서 하나의 대표 사진을 바꿔 공개 페이지에 바로 반영되는지(저장하면 캐시를 바로 비운다).
- 서버의 부서 id가 바뀌면(부서를 지우고 다시 만들면) 상수의 `backendId`도 같이 바꿔야 한다.
